Offline + Online Progressive Web App (PWA) & Google Sites

I-download ang `sw.js` (Service Worker) at `manifest.json` at ilagay sa parehong VS Code folder ng iyong `index.html`. Kapag binuksan ang site nang isang beses habang online, gagana na ito kahit walang internet (Offline) sa phone o computer!

1. Offline Service Worker (`sw.js`)

Sine-save sa cache ng phone/browser ang buong Digital Calling Card, mga parokya, `.vcf` generator, at QR code para mabuksan kahit walang signal.

2. Web App Manifest (`manifest.json`)

Para ma-install ang COTG Connect sa Home Screen ng Android, iPhone, at desktop na parang native mobile app.

3. Google Sites Embed Code

Sa Google Sites, pumunta sa Insert → Embed → Embed Code at i-paste ang code sa ibaba (palitan ang URL ng iyong GitHub Pages link, o i-paste ang buong Public `index.html` code):

Step 1: I-customize ang Impormasyon at Mag-upload ng Logo Dito

Pindutin ang Upload Logo sa itaas para ilagay ang official logo ng Church of the Temple of God. Gamitin ang Edit Church Info para i-check o i-update ang phone number, address, at links ng HQ, 10 Parish Priests, Mission, at Members.

Step 2: I-download ang mga Files papunta sa VS Code Folder

Gumawa ng folder sa iyong Mac (hal. cotg-connect) at buksan sa VS Code. Sa modal na ito, i-download ang: (a) Public Read-Only index.html, (b) sw.js, at (c) manifest.json para gumana nang offline at online.

Step 3: I-push sa GitHub at I-enable ang Security + GitHub Pages

I-push ang folder sa iyong GitHub repository. Buksan ang Settings → Pages (Branch: main, Enforce HTTPS: Checked). Siguraduhing naka-on ang Two-Factor Authentication (2FA) at Branch Protection sa GitHub para walang ibang maka-edit ng code.

Step 4: I-embed sa Google Sites

Sa Google Sites ng simbahan, pindutin ang Insert → Embed → By URL (ilagay ang GitHub Pages URL mo) o Embed Code para lumabas nang buo ang interactive card sa loob ng Google Sites.

Step 5: Gumawa at Mag-print ng Physical Card sa Adobe Photoshop

Pumunta sa Tab 1 (Photoshop Physical Card) dito sa modal, i-uncheck ang Show Trim & Safe Zone Guides kapag handa nang mag-export, at i-click ang Download Front Card at Download Back Card (300 DPI PNG). Buksan sa Adobe Photoshop (3.5" × 2" with 0.125" bleed, 300 DPI, CMYK/sRGB) at i-save bilang Print PDF/TIFF para maipamigay sa mga miyembro at bisita!
